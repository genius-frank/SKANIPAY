# SkaniPay 🇰🇪 🚀

**Scan • Pay • Done**

SkaniPay is a professional, high-speed payment assistant designed to eliminate the friction and errors of manual typing in the Kenyan M-Pesa ecosystem. By leveraging machine learning for text recognition and voice access, SkaniPay ensures that users never send money to the wrong person again.

## 🌟 Key Features

- **Turbo-Charged Camera Scanning**: Instant detection of Paybill, Till, Agent, and Phone numbers from stickers or posters.
- **Smart Alphanumeric Extraction**: Intelligently identifies labels like "PB:", "ACC:", and "TILL:" to extract only the necessary codes.
- **Voice-to-Pay**: Speak out a phone number for "Send Money" transactions—perfect for avoiding typing errors with large fingers.
- **Recipient Name Lookup**: Automatically checks your phone's contacts to verify who you are sending money to (e.g., "Confirm sending to Mary").
- **Professional Workflow**: A clean, scrollable confirmation screen with a "Yes/No" dialog before any transaction is initiated.
- **Dual-Field Support**: Scans both Paybill and Account numbers simultaneously for business payments.

## 📱 Supported Services

- **Send Money**: Scan or speak the recipient's phone number.
- **Withdraw Cash**: Scan both Agent and (optional) Store numbers.
- **Buy Goods & Services**: Scan Till numbers instantly.
- **Pay Bill**: Simultaneous scanning of Business Number and Account Number.
- **Pochi la Biashara**: Quick scanning for small business payments.

## 🛠 Tech Stack

- **Framework**: Flutter
- **Machine Learning**: Google ML Kit (Text Recognition)
- **Voice**: Speech-to-Text
- **Contacts**: Flutter Contacts
- **Platform**: Android (Targeting API 36/37)

## 🚀 Getting Started

1. Clone the repository.
2. Run `flutter pub get`.
3. Connect your Android device (ensure USB debugging is on).
4. Run `flutter run`.
